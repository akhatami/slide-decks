# Slide decks

## [Five Dials](five-dials/)

A live, phone-polled talk about how we use Claude and GPT. `five-dials/index.html` is the deck, the phone voting page and the results panel in one file.

- Open the page to present. The QR code on screen opens the voting page on phones.
- Keys: `→` next, `←` back, `↓` bonus poll, `A` results and setup, `Q` big QR code, `D` demo data, `F` full screen, `T` timer, `L` bright room.
- Answers travel through the public ntfy.sh relay by default (about 25 phones per Wi-Fi). For a bigger room, add a Firebase Realtime Database URL in the `A` panel.
